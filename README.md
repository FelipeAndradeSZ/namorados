# Nosso Universo

Uma experiência romântica interativa construída com React, Vite, Tailwind CSS,
Framer Motion, Canvas Confetti, Typed.js e Lottie React.

## Executar

```bash
npm install
npm run dev
```

## Personalização inicial

Edite `src/config/loveStory.js` para definir:

- o nome do casal;
- o texto de introdução;
- a data e o horário em que o relacionamento começou.

A data deve seguir o formato ISO com fuso horário, por exemplo:
`2024-06-12T20:00:00-03:00`.

## Fundação visual

- aurora animada inspirada em Aceternity UI;
- spotlight suave que acompanha o cursor;
- partículas determinísticas e acessíveis;
- revelação de texto por palavra;
- contador de relacionamento atualizado em tempo real;
- suporte a `prefers-reduced-motion`.
